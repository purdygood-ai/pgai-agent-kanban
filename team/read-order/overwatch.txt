# team/read-order/overwatch.txt
# Read-order manifest for the OVERWATCH role.
#
# One path per line, relative to the kanban root as the RUNTIME layout
# resolves it -- install.sh flattens team/ onto the kanban root, so a
# line here reads "roles/OVERWATCH.md", never "team/roles/OVERWATCH.md".
# Blank lines and lines starting with # are ignored.
# team/scripts/lib/read_order.sh resolves this file into an ordered
# list of absolute paths that the wake composer
# (_wd_build_governance_line in team/scripts/lib/wake_governance_composer.sh)
# assembles into this role's governance reading list.
#
# OVERWATCH sits outside the six-agent RC pipeline, but every role in
# the catalog gets a manifest. The shared law it reads is SOP-core.md:
# the per-repo wake lock lives in the role file below, and core
# carries only what every role must read. The per-project README is
# conditional at runtime (present only in multi-project mode) and
# stays the composer's job to append, not a static manifest line.
