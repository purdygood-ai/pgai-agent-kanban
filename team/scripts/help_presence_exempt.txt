# help_presence_exempt.txt
# Exempt list for lint_help_presence.py.
#
# Each line names a script exempt from the help-presence lint requirement:
# a bare basename, or a trailing path such as wake/claude.sh; an entry
# matches every scanned script whose path ends with it.  Blank lines and
# lines beginning with # are ignored.  Sourced libraries (any lib/
# directory) and workflow plugins are exempt by the lint's own rule and are
# never listed here.
#
# Exemption categories:
#
#   dashboard-internal  Scripts invoked by the dashboard rendering engine
#                       rather than by operators directly.  They receive
#                       arguments from the dashboard and are not exposed
#                       on the operator command line.
#
#   process-internal    Scripts invoked by other scripts (cron, batch
#                       dispatcher, overwatch runner) and not exposed on
#                       the operator command line.  They do not accept
#                       operator flags and have no help surface.
#
#   library-parsed      Thin shims that hand "$@" to a sourced library,
#                       which parses the command line and answers --help
#                       itself.  The shim's own text has no handler for
#                       the lint to see.
#
# ---------------------------------------------------------------------------

# loop prints the wake usage and exits 0 on --help/-h.
