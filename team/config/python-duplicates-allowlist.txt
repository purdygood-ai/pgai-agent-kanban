# team/config/python-duplicates-allowlist.txt
#
# Ratchet baseline for duplicated Python under team/pgai_agent_kanban,
# team/scripts and team/pm-agent, read by team/scripts/lint_python_duplicates.py
# (quality class, never fatal). Format: one
# "<family>\t<path>\t<symbol>\t<count>" line per finding key, path relative to
# the repository root. <symbol> is the defining function's dotted qualified
# name, or for ini-instantiation and state-regex the enclosing function's
# (<module> at top level). Families and owning modules are documented in the
# lint's module docstring. A finding whose key is not listed here is reported.
#
# Ratchet rule: an entry is lowered or removed when a copy is replaced by an
# import, and is never raised or added. The lint reports an entry above what
# it measures so the entry is tightened in the same change; its
# --emit-allowlist mode prints the measured keys in this format.
