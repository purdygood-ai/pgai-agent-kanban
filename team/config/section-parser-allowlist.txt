# team/config/section-parser-allowlist.txt
#
# Sites that detect a markdown "## " heading outside the section reader
# (task_status.read_section, read_md_field) and read no value, read by
# team/scripts/lint_section_parsers.py (quality class, never fatal).
# Format: one "<path>\t<class>\t<reason>\t<code>" line per site, path
# relative to the repository root, <code> the site's line with its
# whitespace runs read as one space. <class> is one of: section-writer,
# ledger-heading, heading-counter, structure-lint, presence-check,
# remedy-text, header-exempt. A site that reads a value is never listed
# here: it moves to the reader.
#
# Ratchet rule: an entry is removed when its site is, and the lint reports
# an entry that names no site so it is removed in the same change. A new
# entry is added only for a new site of one of the classes above;
# --list-sites prints every site the lint finds.
