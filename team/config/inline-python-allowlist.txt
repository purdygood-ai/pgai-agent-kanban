# team/config/inline-python-allowlist.txt
#
# Per-file ceiling on inline Python in non-test bash under team/scripts and in
# install.sh, read by team/scripts/lint_inline_python.py (quality class, never
# fatal).
# Format: one "<path>\t<blocks>\t<python_lines>" line per file, path relative
# to the repository root. A file not listed here must carry no inline Python.
#
# Ratchet rule: an entry is lowered or removed when inline Python is moved
# into a module, and is never raised. The lint reports a file below its
# entry so the entry is tightened in the same change; its --emit-allowlist
# mode prints the measured counts in this format.
